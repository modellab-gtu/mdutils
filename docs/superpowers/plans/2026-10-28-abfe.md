# mdutils ABFE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GROMACS absolute binding free energy and hydration free energy workflows to mdutils (`abfe_setup.sh`, `abfe_analyze.sh`), built on mdutils MD run folders, and validate them.

**Architecture:** There is one Python package, `automd/fe/abfe/`, with one module per job: run-folder reading, λ schedule and MDPs, topology editing, co-alchemical ions, Boresch restraints, Slurm files, analysis. Two thin bash launchers in `bin/` run it with the ligparam Python. Each λ window is one Slurm array task (EM→NVT→NPT→prod); analysis uses alchemlyb MBAR + TI.

**Tech Stack:**
- Python 3 (ligparam env): MDAnalysis 2.11, MDRestraintsGenerator 0.2.1, alchemlyb 2.5.0, pymbar 4.0.3, numpy/pandas/matplotlib/yaml, pytest.
- GROMACS 2026.1 modules (`gromacs/2026.1-tmpi`, `gromacs/2026.1-tmpi-cuda`).
- Slurm.

**Spec:** `docs/superpowers/specs/2026-10-28-abfe-design.md` (read it first; this plan does not repeat its rationale).

## Global Constraints

- **Repo and branch:** `/cta/users/akocak/mdutils`, branch `abfe`.
  - Never touch the installed clone `/cta/capps/envs/ligparam/opt/mdutils` or the live module `/cta/etc/mod/mdutils/2026.10.lua` before the user merges and promotes.
- **Python:** `/cta/capps/envs/ligparam/bin/python`. Tests run with `/cta/capps/envs/ligparam/bin/python -m pytest tests/fe`.
- **Package versions:** alchemlyb 2.5.0, pymbar 4.0.3, MDRestraintsGenerator 0.2.1, alchemtest (latest, tests only).
  - The install must not change the version of any package already in ligparam. Compare `pip list` / `conda list` before and after.
- **Units:** GROMACS units internally (nm, kJ/mol, degrees in topology, radians in formulas). Results are reported in kcal/mol and kJ/mol, with 1 kcal = 4.184 kJ. kB = 0.0083144626 kJ/mol/K. V° = 1.66054 nm³.
- **Default schedules:**
  - Complex: restraint `0 0.05 0.1 0.2 0.5 1` then Coulomb `0..1 step 0.1` then vdW `0..1 step 0.05`, which is 36 states.
  - Solvent: Coulomb then vdW, which is 31 states.
- **FE MDP keys:**
  - `free-energy = yes`, `couple-moltype = <LIG>`, `couple-lambda0 = vdw-q`, `couple-lambda1 = none`, `couple-intramol = no`;
  - `sc-alpha = 0.5`, `sc-power = 1`, `sc-r-power = 6`;
  - `nstdhdl = 100`, `calc-lambda-neighbors = -1`, `dhdl-print-energy = total`, `separate-dhdl-file = yes`, `init-lambda-state = N`.
- **Per-window protocol:** steep EM, then NVT 100 ps, then NPT 200 ps (C-rescale), then production. Production is 5 ns (complex) or 3 ns (solvent). Cutoffs, PME, tc-grps and `ref_t` are copied from the run folder's `MDP/md.mdp`.
- **Slurm:**
  - gtu complex: `-p main -w cws01 --gres=gpu:1 -c 8`, `module load gromacs/2026.1-tmpi-cuda`, `CUDA_DEVICE_ORDER=PCI_BUS_ID`.
  - gtu solvent: `-w cws02 -c 8`, `gromacs/2026.1-tmpi`.
  - TRUBA: same conventions as `automd/common/run_files.sh` (1 rank × `TRUBA_OMP` threads, no mpirun when ntasks = 1; `gmx_mpi`; `-C weka`).
  - The tpr is always rebuilt inside the job.
- **Analysis warning thresholds:** overlap below 0.03; forward/backward difference above 0.5 kcal/mol; MBAR vs TI difference above 0.5; repeat spread (max − min) above 1.0.
- **Never run jobs from chn `/tmp`.** Test run folders live under `/cta/users/akocak/maint/abfe_test`.
- **Commits:** on branch `abfe`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Topology written by the ParmEd route** (`lig_solv_gmx.top`, everything inline, ion moleculetypes named `NA`/`CL` or `Na+`/`Cl-`), not only the pdb2gmx `topol.top` with includes. Setup must find the topology from `run_md.sbatch`'s `-p` and work for both. Test: Task 4 runs on both fixture folders.
2. **Ligand moleculetype name differs from residue name** (for example moleculetype `JZ4` with residue `JZ4`, but a ParmEd route might call the moleculetype `LIG` or `system1`). Setup must error clearly if `--ligand` matches no `[ moleculetype ]`. Test: Task 4 `test_missing_ligand_moleculetype`.
3. **A window that crashed mid-production** must restart: rerunning the array task skips completed steps and continues from `prod.cpt`. Test: Task 7 asserts the generated sbatch uses `-cpi` and skips on non-empty `.gro`.
4. **Partial results:** running `abfe_analyze.sh` while some windows are still running must refuse that leg with a list of missing λ indices, not crash in alchemlyb. Test: Task 9 `test_missing_window_refused`.
5. **The second run of `abfe_setup.sh` into an existing `--outdir`** must refuse unless `--overwrite` is given, so finished windows are never wiped. Test: Task 7 `test_refuses_existing_outdir`.

### Task 9: Analysis

**Files:**
- Create: `automd/fe/abfe/analyze.py` (argparse `main()`), `bin/abfe_analyze.sh`
- Test: `tests/fe/test_analyze.py`

**Interfaces:**
- Consumes: `setup.json`, `boresch.json`, `rep*/lam_*/prod.xvg`.
- Produces:
  - `analyze_leg(rep_dir, T, equil_ns) -> LegResult`, where `LegResult(dg_mbar, err_mbar, dg_ti, err_ti, min_overlap, fwd_bwd_diff, n_states)`, all in kJ/mol except overlap. It:
    - discards the first `equil_ns`;

  - `warnings(...) -> list[str]`, using the Global Constraints thresholds.
  - **Output files:**
    - `results/abfe_result.txt`: human-readable, with the sign convention spelled out;
    - `results/abfe_result.csv`: columns `quantity, repeat, estimator, value_kcal, error_kcal`;
